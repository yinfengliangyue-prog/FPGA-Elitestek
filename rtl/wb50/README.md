# 50 整合版三通道自动白平衡

用户最新要求采用自动模式，R/G/B 三通道均能变动，不需要手动模式。本目录只实现三通道 AUTO；沿用整合版原来的 AUTO/LOCK 操作。没有 MANUAL、示例预设、肤色分类或固定修蓝系数。

默认 `final_wb24.RGB_AUTO=1` 使用 `awb_grayworld_rgb_2ppc`。有效像素筛选、低照度/绿色偏色后备筛选、最小样本数、增益上下限与慢更新均沿用原方案，但每帧三个目标增益改为：

`target_C = round((sum_R + sum_G + sum_B) * 256 / (3 * sum_C))`，其中 `C` 分别为 R、G、B。

这等价于把三通道均值校正到该帧 RGB 的算术平均值，不再固定 G=256。计算先对足够的原始 RGB888 合格样本累加，不经过 RGB565 或 Gamma；每通道目标限于 128～640 Q8，更新按 1/16 距离向上取整、每帧最多 16 Q8。一个共享恢复除法器每通道 42 拍，共 126 拍，三通道在 B 通道计算结束后同拍提交。统计不足、暗噪声、饱和或强彩色场被拒绝时保持原增益；AUTO 关闭或 LOCK 时停止提交增益。

`rtl/wb24/final_wb24.v` 保留原模块名与原命名端口连接，只追加 `gain_r/gain_g/gain_b[11:0]` 输出。它们是本输入帧 SOF 时两条色彩 lane 实际使用的 Q8 增益，包含 G 通道；不是估计器待生效的下一组数值。`lock_request` 在帧中到达时锁存最近一帧实际值；与 SOF 同拍到达时锁存该拍实际值。三个增益一起锁定，冻结 DDR 中的图像不会重染。

新增工程源仅 `rtl/wb50/awb_grayworld_rgb_2ppc.v`。既有原始 R/B 估计器仍保留在 `rtl/compare23`，用于 `RGB_AUTO=0` 的回归兼容模式，该模式 G=256；默认产品路径为三通道 AUTO，不使用此兼容模式。旧按位置连接的测试需改为命名连接，因为新增了三个输出。

色彩通路仍为完整 RGB888 → SOF 增益 → 原 Q8.1 Gamma 2.2 → 轻度锐化 → 后续图像压缩，锐化继续复用单彩色行，整体延迟仍为 HT+7。新的估计器不增加图像数组/行缓存，Canny 校色前分支不需改变。新 RGB 统计器与旧估计器保留相同采样和置信策略，但三通道归一化会改变绝对亮度，需上板评估。

Gamma 的原始512项数值全部保留，改为216组case表达；最终237RAM的正式映射中，两条lane仍各使用3块ROM，合计6块。该case改写没有实现物理RAM减少，不把理论目标计入节省。原ROM仅作为验证参考，位于 `verification/wb50_reference/color_enhance_rgb888_rom_ref.v`。

用户报告的蓝调与淡蓝人脸尚未由此工程实物复测；本改动让三通道具备自动纠偏能力，不把仿真通过表述为现场偏色已经消除，也不写入未经用户确认的现场校准文件。
