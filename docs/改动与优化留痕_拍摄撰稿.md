## 白平衡：完整方法与校准落地

生产路径为：53等价CFA映射 → 原RGB三通道灰世界统计 → AUTO目标 → 有效Q8校准/限幅 → 三通道帧边界原子发布 → 原53颜色乘法与Gamma2.2 → Gaussian与限幅轻锐化 → 缓存/显示。

- 上电/复位实际使用R320、G158、B329（Q256=1倍），不是先从三路256开始等待自适应。
- AUTO有效范围：R304～336、G151～165、B313～345。每个接受更新、每通道最多1 Q8，在有效首像素同时生效；坏样本保持，LOCK冻结实际有效值。
- 保留53的过滤样本、低照fallback、共同均值目标、整数舍入与平滑。绿色224/256仅用于原AUTO估计目标转换；**基准G158和LOCK值已经是有效增益，不再乘一次0.875**。
- 保留半曝光00/5D/60，Gamma2.2、锐化strength4/detail16固定开启。没有新增滤波开关或RGB手调；菜单只提供AUTO/LOCK和三路有效Q8只读值。
- 53的CFA0等价变换只用于WB支路：对原Debayer输出交换R/B，逐通道插值等价；原Canny仍接FINAL03未加WB的输入，避免校准增益/颜色相位改变检测条件。
- 原53的垂直滤波以RGB原值配合亮度邻域作限幅轻锐化，并非全RGB强平滑器。“降噪/锐化”沿用既有实现，不额外宣称采用新的空间降噪算法。
- 为片内RAM使用等价紧凑垂直行缓存，保留原算术与边界行为；用原53字面实现作逐像素对照。不能仅因模块名类似就宣称方法相同，实际对照记录保存在验证日志。

摄影/写作可表述为“采用用户实物确认的三通道颜色基准，并允许有限自动微调”。不能写成仪器测得零色差，也不能宣称任意照明下均最优。

## 52全部缓存功能的整合

主功能仍是FULL → FRAME → SHAPE → NUMBER → EXPR；原SPLIT缓存功能由FRAME的LIVE / REPLAY / COMPARE三页替代。

| 功能 | 当前行为 |
|---|---|
| 自动录像 | 上电开始一段最多120个处理输出帧，录满锁存，实时继续 |
| LIVE | 两窗同一当前帧，默认WB/BAL |
| REPLAY | 左实时、右历史，播放/暂停、0.5×/1×/2×、到尾循环 |
| 逐帧 | SW2上一帧、SW3下一帧；长按连续，每次仅1帧，端点饱和，手动步进暂停播放 |
| COMPARE | 左历史A、右历史B，默认最早/最后；对象、帧号和样式独立，可选同帧 |
| 元数据 | 有效帧数、A/B帧号、写入完成时间差、双游标 |
| 提前停止 | LIVE中的停止并回放动作，保留已完成帧 |
| 重录 | 菜单NEW TAKE，经确认后排空读/写，清理历史并开始新一段；保留检测阈值 |
| FULL暂停 | 独立保留当前全屏帧，可更新或恢复LIVE；不用旧A/B/SYNC缓存体系 |

120帧不是滚动保存最近120帧；返回LIVE保留本段，只有明确重录会覆盖。按60Hz处理输出名义约2秒，传感器较慢时可能重复曝光。时间戳是1ms精度、16bit模65.536秒的写入完成时刻，不是曝光起点；未增加掉电存储。

52旧物理组合键不接入本工程，只复用语义动作。SW0切主功能，SW1设置开关；重录通过菜单确认，所有多键手势取消。原三键组合没有回流到新控制器。

## 片内RAM与外部DDR的不同优化

两者分别预算，不能把“120帧放外部DDR”写成“完全不占片内RAM”。

**外部DDR：** 256MiB；RAW三槽预留结束0x00BDDE00，处理区起点0x00C00000。处理帧960×540、每像素32bit，2,073,600字节，槽跨度4KiB对齐为0x001FB000。120历史+3实时槽结束0x0FF99000，距离0x10000000余421,888字节。保留52原物理分区，不能叠加FINAL03六个4MiB槽；旧独立A/B/SYNC时间线已被52历史选择机制替换。

**32bit记录：** BAL8 + CLEAN8 + 已检出边缘1 + 标注1 + RGB55414。保留FINAL03既有RGB554量化、完整8bit BAL/CLEAN和形状标注；不保存旧NMS/强度供冻结缩图重分类，新UI也没有该旧预览操作。全分辨率先算边缘/BAL/CLEAN，再2×2池化，不能把缩图邻域重算冒充原算法。

与52独立版的RGB887相比，本整合版彩色记录为RGB554，这是容纳双效果/标注且保留120帧的明确取舍；与FINAL03当前彩色缓存精度相同。WB统计、增益、Gamma和滤波仍以RGB888执行，量化发生在显示/缓存配对处。论文中不应将缓存彩色说成无损RGB888。

**片内共享：** 只实例化一套WB、一套Canny、一套49 BAL/CLEAN，形状复用同一检测流；移除旧冻结缩图再连接/重分类链，记录队列由32bit元数据降到16bit，删除无用NMS保存。DDR吞吐从48bit快照降为32bit，处理帧每帧数据减少1/3；FIFO仍按生产深度验证。

**GRAY：** 当前保留。GRAY由已存彩色即时计算，不新增图像平面，移除GRAY不会释放独立帧缓存或行RAM。先做共享/记录压缩，再以真实综合布局报告判断，不把删除菜单名当成RAM优化。

## 菜单与拍摄便利

- 左下角主功能/样式/状态短提示从120显示帧改为300显示帧，1080p60名义5秒；计数器加宽为9bit，避免300在8bit计数器中截断。
- Canny彩色红边/BAL/CLEAN与SHAPE：GLOBAL H、GLOBAL L、GLOBAL DENOISE置顶。首次打开和每次重新打开都选第一优先项。
- FRAME LIVE按所选样式决定是否先展示H/L；REPLAY优先播放/历史帧/速度；COMPARE优先对象/A帧/B帧。历史页中的H/L明确为GLOBAL，只影响之后采集，不重算历史。
- 切换菜单上下文时结束当前编辑，防止PAGE切换后按键误调新的第一项。WB有效Q8只读，不假装可以人工调节。
- 菜单沿用右侧六行卡片、黄选中/青编辑、单键上下/确认、显式关闭且无超时。关闭后无帮助残留，适合拍摄；NUM/EXPR的768搜索框和未知结果布局保留。
- SHAPE仍有真实结果/标注原子锁定；NUMBER/EXPR没有后端，显示“?”/WAIT，无结果不进入假LOCK。

## 本轮额外实际修正

- 读地址选择与显示布局统一取同一显示帧的主功能快照，避免按键在帧边界附近改变布局/来源的先后次序。

- RTL预览发现帧号/毫秒行原字符串超出32字符，导致首字截断及数字错位；现按32字符对齐，并加A001/B120/N120/DT01990MS和LIVE DONE文本检查。
- 首轮布局后有一条原形状OBB路径setup为-0.062ns；保留算法和SDC，调整布局种子后重跑，最终结论以构建报告为准。此过程说明综合/生成bit成功不足以代表时序收敛。

全高清证据分为WB53算术/边界逐像素对照与32bit reader→raster→两级UI→HDMI输运检查；完整RAW/120帧/共享DDR/回放控制使用缩小合成输入。没有把中断的全管线HD试跑列为通过，也没有声称完成120个1080p原始相机帧的仿真或实拍。
