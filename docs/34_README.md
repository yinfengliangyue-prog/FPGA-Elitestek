## 操作与功能

上电为OFF。SW0短按松开：`OFF → NUMBER → EXPR → OFF`。
EXPR确认结果后，长按SW0约1秒并松开锁定；再次长按解锁。校准后的启动等待约14ms，识别确认另需完整分析时间。
SW1～SW3保持参考引脚为输入，不添加Canny阈值或其他按键功能。P13是LED引脚，不作为图像复位。

保留原有算式能力：

- 数字0～9识别；算式为一行、两个0～99的非负整数和一个运算符。
- 支持 `+`、`-`、交叉 `×`/X、斜杠 `/`；除法显示整数商和余数，除零显示DIV0，减法可显示负数。
- 三次完整分析一致后READY，锁定期间视频仍实时更新。
- 搜索区768×768，左上角(576,156)；初始实际裁取范围每边扩4像素，并有ROI及邻字保护。EXPR屏幕小框显示稳定后的实际采样范围；符号几何与算式校验仍使用本次原始定位范围。
- 字符之间保留明显空白；纸上不写等号和答案。不支持小数、负数输入、括号或多个运算符。

逻辑LED状态：led[0]为DDR校准后心跳；led[1]为识别模式使能；led[2]为数字/算式确认；led[3]为HDMI转换故障。参考板物理D6对应转换故障，正常应灭。

## 抗噪处理与诊断

仅EXPR模式启用新处理。先收集最多32个达到原8格门槛的连通组件，再以至少两个高度和竖直位置相近、横向分离的组件定位主行。强度相同的分离双行拒绝；组件按中心是否落在主行带内整块保留或去除，不在行带边缘裁断笔画。

主行内宽高都小于主字高度1/4、且高度未达到原数字最小8格的紧凑小点被筛除。达到原高度门槛的小数字及宽度至少8格、宽高比至少3的减号受保护；强细长的断开小笔画可归并到邻近主体。真正与笔画粘连的干扰仍可能无法区分，小点与正常小内轮廓形状相同时也存在误删风险。

本版只用于整数算式。几何筛点无法区分污点与有意写下的小数点，小数点也可能被删除，因此不要用含小数点的输入检验算术结果。

清理之后才按列分割3～5字符，并按组件标签限定归一化采样归属，防止扩框读入其他组件。正常大小的额外字符不会为了凑算式而删除：`2+39`保留四字符；六字符或多个运算符仍拒绝。容量32是组件而非字符数，候选表或BFS队列溢出仍拒绝。

清理作用于识别数据，摄像头画面及红色边缘预览仍显示现场内容，因此被忽略的小点可能仍然可见；可通过DROP计数和正确字符框核对筛噪效果。

屏幕第三行 `TOK/CAND/DROP/CODE` 分别为有效字符数、原候选组件数、剔除组件数、拒绝原因码。DROP包含原有不足8格碎片，显示最大99；诊断与算式同帧更新且随结果锁定。

| CODE | 含义 |
| --- | --- |
| 0 | 预处理正常 |
| 1 | 无法确定主行或存在同等支持的分离主行 |
| 2 | 清理后仍超过5字符 |
| 3 | 选中主体触搜索框边界或过大 |
| 4 | 组件表或搜索队列溢出 |
| 5 | 空白或有效字符不足 |
| 6 | 字符置信度/运算符/算式解析失败 |

`number_video_pipeline` 的 `EXPRESSION_NOISE_FILTER=0` 可退回旧分割作对照，默认1。

## 稳定裁取与短暂漏检

仅EXPR模式稳定采样范围，不混合历史像素。字符数一致且每个原始框端点与建立跟踪时的参考位置相差不超过4格时复用窗口；当前笔画仍在窗口内且期望边界变化不超过1格时保持。任何当前笔画越界立即扩张；某边连续3次有超过1格的收缩余量时才向内走1格。每次均重新检查当前邻字间隙，不允许采入相邻字符。字符数改变、累计位移/尺寸变化超过4格、模式退出或12个视频帧未成功定位时丢弃历史，防止连续慢移导致窗口逐渐变大。NUMBER路径保持原处理。

默认参数：`CROP_STABILIZE=1`、`CROP_DEADBAND_CELLS=1`、`CROP_SHRINK_ANALYSES=3`。每格为4个原图像素；设`CROP_STABILIZE=0`可对照原逐次裁取。

仍须连续3次整式一致才READY，没有改成五次投票，也没有降低数字置信度门槛。已经确认后遇短暂空白/置信度失败，屏幕保留上次文字和框，明确显示`EXPR LIVE WAIT LAST`并改为黄色框，READY及锁定资格取消。200ms计时从第一次失败开始，后续失败及同式未确认观察不能重启计时；超时在下一视频帧边界清除显示，因此可多保留至多一个显示帧。不同有效算式、框明显移位（超过8格）、结构性错误CODE 1～4立即退出保留。只有重新确认才恢复READY；OFF、解锁清除历史。

`VIDEO_CLK_HZ=74250000`、`EXPRESSION_WAIT_MS=200`对应14,850,000拍计时；可设`EXPRESSION_WAIT_MS=0`关闭漏检保留。WAIT LAST表示历史结果，第三行诊断反映当前失败。稳框不增加`÷`识别能力：本次没有实现此前讨论的横线上下两点保护，除号仍使用斜杠`/`。
