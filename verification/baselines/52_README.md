## 三种显示模式

| 模式 | 实际处理 |
|---|---|
| AUTO WB | R/G/B三通道灰世界自动增益，整帧同时更新；线性RGB，无Gamma或空间锐化 |
| RED | 在同一自动白平衡底图上，将Canny检出的边缘标红 |
| BAL | 49/50同款连续性恢复与强线提亮，在最终Canny边缘之后计算 |

模式顺序 AUTO WB → RED → BAL → AUTO WB。没有独立原始RGB、GREY或BW选项。Canny以42原始RGB作为输入，自动白平衡和BAL不反馈检测；默认H6/L3、去噪开启，两次有限邻域连接，不宣称完整全帧滞后追踪。

先在1920×1080上计算Canny和BAL，再做2×2缩小：BAL取最大、红边掩码取OR、白平衡彩色取左上像素。为保留120帧而维持32bit记录，彩色保存R8/G8/B7，仅舍去蓝通道最低1bit，显示时复制蓝最高bit补足；相对白平衡RGB888的误差最多1级，BAL保留完整8bit。这不是把旧Sobel/BW重命名为BAL。

## 120帧缓存与画面

上电自动录制一段最多120个处理输出帧。录满或进入回放后锁住历史，实时继续；返回LIVE保留历史，SW0+SW3明确开始新一段。它不是滚动覆盖最近120帧，断电不保留。按60Hz输出名义约2秒，传感器较慢时可能重复曝光。

| 页面 | 左窗 | 右窗 | 默认模式 |
|---|---|---|---|
| LIVE | 当前帧 | 同一当前帧 | AUTO WB / BAL |
| REPLAY | 当前实时帧 | 历史帧，播放或暂停 | AUTO WB / AUTO WB |
| COMPARE | 历史帧A | 历史帧B | BAL / BAL |

对比页默认A为最早帧，B为最后一帧。SW3选对象，金色边框/游标跟随选中对象；两边独立选帧、独立切模式。相同帧号允许比较显示效果，界面显示零时间差；不同编号用于比较不同时刻。下方显示帧号、有效总数、实际写入完成时间差及双游标。

每窗960×540，保留完整视野，在1080p画面中上下居中。页签、标题、状态、时间轴、按键说明全部放在图像之外，无浮窗、点击或触屏。空历史窗为黑色/000，不引用未发布帧。

## 按键

详见《按键速查.md》。短按在完整松手后执行一次；SW1/SW2长按约600ms开始逐帧连发，之后每150ms前进/后退1帧，松手不附加一次操作。SW0/SW3长按只执行一次，并取消相应短按。组合键错峰松开不触发单键。

| 操作 | 功能 |
|---|---|
| 短按SW0 | LIVE → REPLAY → COMPARE → LIVE |
| 长按SW0 | 切所选窗的 AUTO WB / RED / BAL；LIVE/REPLAY作用于右窗 |
| 短按或长按SW1/SW2 | REPLAY逐帧并暂停；COMPARE所选A/B逐帧；长按连续、端点饱和 |
| LIVE的SW1/SW2 | Canny公共H减/加，1～255；长按连续；L=min(3,H)，H6/L3上电/复位 |
| 短按SW3 | LIVE停止录制并进入回放；REPLAY播放/暂停；COMPARE选A/B |
| 长按SW3 | 仅REPLAY：1× → 2× → 0.5× → 1× |
| SW0+SW3 | 排空正在进行的读/写后开始新一段；保留手调H/L |

没有±10帧功能。回放自动到尾循环，手动逐帧在头尾停止。历史保存的是当时处理结果，之后调H不重算既有历史；LIVE显示当前H/L，历史页不标成当前阈值重新处理。

只占用1组组合键，其余10组预留，尤其保留50使用的SW1+SW2菜单、SW0+SW1 SAME、SW0+SW2 AWB LOCK、SW0+SW1+SW2 HELP、SW2+SW3恢复实时及全键恢复等组合。尚未改动50的实际按键。`scope_enable`和语义动作接口见《按键整合接口.md》。

## DDR与片内RAM

按用户指定20261012原理图第7页，U12 MT41J128M16JT-125容量128M×16bit，共256MiB。本版保留DDR3软核，未改称硬核。

RAW三槽最大预留结束 `0x00BDDE00`。处理区从 `0x00C00000` 开始，每帧960×540×32bit=2,073,600byte；4KiB对齐跨度 `0x001FB000`。0～119为历史，120～122为实时。123槽结束 `0x0FF99000`，距物理上限 `0x10000000` 余421,888byte。自动审计见 `verification/MEMORY_BUDGET.json`。

120帧占外部DDR；片内仍需要Canny行缓存、BAL邻域缓存、白平衡色彩配对队列和读写FIFO。相对旧Sobel52，实际片内RAM会增加，不能说加入这些算法完全不占RAM。白平衡色彩只为每个2×2块排队一次，避免整条双像素RGB长延迟链；生产处理区读/写FIFO维持1024深，RAW FIFO512深。

最后一个AXI B响应成功才发布完整帧，错误不计数；历史锁住后不会被实时覆盖，实时三槽排除最新帧及在读槽。重录排空在途读写，元数据和左右地址同事务发布；burst不跨4KiB。时间戳为1ms写入完成时间，16bit模65.536秒，非曝光起始时间。
